# Yugatirtha — Journeys Through Time

> Curated sacred, domestic, and international journeys planned with care for story, season, and sacred ground.

## Overview

Yugatirtha is a modern, high-performance web application built with React 19, Vite, Tailwind CSS v4, and Framer Motion. It features detailed, curated travel itineraries across:
- **Domestic Circuits**: Kashmir, Ladakh, Himachal, Spiti Valley, Meghalaya, Sikkim, Arunachal Pradesh, Rajasthan, and South India.
- **International Journeys**: Bali, Japan, Sri Lanka, Philippines, Georgia, Vietnam, Cambodia, and the Silk Road.
- **Consecrated Spiritual Journeys**: Char Dham, Do Dham, Kainchi Dham, Kashi-Ayodhya, Panch Bhoota Stalam, Jyotirlinga circuits, Puri Jagannath, and Shakti Peeths.
